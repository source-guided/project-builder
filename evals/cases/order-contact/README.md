# 주문 배송 연락처 관리

빈 프로젝트에서 한국어로 사용할 수 있는 작은 웹 앱을 만든다. 사용자는 여러 주문을 확인하고 배송 연락처를 차례로 수정하는 운영 담당자다. 제공된 `orders.json`은 가상의 테스트 데이터다.

- 주문번호, 상품 목록, 배송 상태와 현재 수령인·연락처·주소를 확인한다.
- 배송 준비 상태의 주문만 배송 연락처를 수정할 수 있다. 이미 발송된 주문은 조회만 가능하다.
- 편집 중에도 현재 주문과 상품을 참고할 수 있어야 한다.
- 수령인·연락처·주소는 필수다. 연락처의 앞자리 0을 보존한다. 구체적인 국가별 전화번호 정규식은 요구하지 않는다.
- 저장 전에는 기존 배송 정보가 바뀌지 않는다. 취소는 기존 값을 유지한다. 입력 오류가 나면 작성 중인 내용을 유지하고 바로 고칠 수 있어야 한다.
- 주문 전환 시 작성 중인 변경을 말없이 버리지 않는다.
- 정보와 행동은 이 작업을 완료하는 데 필요한 범위로 구성한다. 통계, 과금, 로그인, 서버와 실제 배송 요청은 범위 밖이다.
- 상태는 현재 브라우저 세션에서만 유지하면 된다. 별도 서버 API와 저장소는 필요 없다.

`index.html`을 로컬 HTTP 서버로 열어 사용할 수 있게 만들고, 실행 방법과 실제로 확인한 결과를 기록한다. 외부 계정이나 네트워크 서비스로 데이터를 전송하지 않는다. 화면을 직접 확인할 수 없으면 그 한계를 표시한다. 제공된 구현 코드는 없다.
